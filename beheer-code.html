Inlogcode maken

Alleen voor de beheerder. Deze pagina is niet gelinkt en verstuurt niets.

Keur je een aanmelding goed, maak dan hier een persoonlijke code. Stuur de inloglink (of de code) alleen naar de adviseur, bijvoorbeeld per mail. Zet de regel voor adviseurs.js in data/adviseurs.js; daarin staat alleen een hash, nooit de code zelf.


    

    

    
Code kwijt? Maak een nieuwe en vervang de regel; de oude code werkt dan niet meer. Een adviseur blokkeren doe je door de regel te verwijderen of geverifieerd:false te zetten.
